# Situation arises
  → Cynefin: What domain am I in?
    → Chaotic? → OODA (Act → Sense → Respond)
    → Complex? → OODA (Probe → Sense → Respond)
    → Complicated? → Slow down. Analyze.
    → Obvious? → Best practice. Don't overthink.

## Before deciding (in any domain):
  → Ladder of Inference: Am I skipping rungs?
  → Pre-mortem: How does this fail?
  → Second-order thinking: And then what? And then what?
  → Inversion: What guarantees failure? Avoid those.

### After deciding:
  → OODA: Act, then loop back to Observe.
  → Box breath: Regulate the dial.
